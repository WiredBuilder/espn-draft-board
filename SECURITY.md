# Security

To report a vulnerability, open a GitHub issue at https://github.com/WiredBuilder/espn-fantasy-hockey-draft-assistant/issues or email blake@fervorc.com. Reports are read within a few days and fixes ship as a new tagged release.

Scope: the plugin sends your ESPN cookies only to ESPN, stores data only in a local SQLite file, and never writes to your ESPN team. Anything that breaks one of those three promises is in scope.
